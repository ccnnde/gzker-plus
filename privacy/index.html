过早客 Plus 隐私政策

更新日期：2026 年 9 月 18 日

过早客 Plus 是一款用于增强过早客（guozaoke.com）使用体验的浏览器扩展。本隐私政策说明扩展访问、处理和存储用户数据的方式。

1. 数据访问

为提供论坛增强功能，过早客 Plus 可能访问用户在过早客网站上的相关页面数据，包括：

  • 当前浏览的过早客页面内容
  • 主题、回复以及用户公开资料信息
  • 用户登录状态相关信息
  • 通知消息相关信息
  • 执行论坛操作所需的网站认证信息

这些数据仅用于实现扩展功能，例如增强主题浏览、用户信息展示、搜索增强、消息增强、回复编辑以及论坛交互功能。

2. 数据收集与传输

过早客 Plus 不运营用于收集用户个人信息的服务器。扩展不会将用户的过早客浏览记录、账号信息或论坛数据上传至开发者控制的服务器。

数据主要在以下位置处理：

  • 用户自己的浏览器环境
  • 浏览器提供的扩展存储功能
  • 用户主动使用的第三方服务

3. 浏览器存储

过早客 Plus 使用浏览器扩展存储功能保存用户配置，例如界面设置、主题设置、屏蔽规则和扩展功能配置。

部分设置可能使用浏览器提供的同步存储功能。如果用户启用了浏览器账户同步功能，这些数据可能根据浏览器同步机制同步至用户自己的其他设备。

4. 第三方服务

过早客 Plus 提供可选的图片上传功能。用户可以选择使用第三方图床服务，包括 S.EE 图床服务和哔哩哔哩图片上传服务。

当用户主动使用这些功能时，用户选择上传的图片以及完成上传所需的信息会发送至对应第三方服务。相关数据处理受第三方服务自身隐私政策约束。

过早客 Plus 不控制第三方服务的数据处理行为。

5. API Key

如果用户配置第三方图床 API Key（例如 S.EE API Key），该信息会保存在浏览器扩展存储中，用于用户主动发起的图片上传操作。

该信息不会发送至开发者控制的服务器。

6. 编辑历史

为避免用户编辑内容丢失，过早客 Plus 可能在用户浏览器本地保存编辑历史数据。这些数据仅用于恢复用户自己的编辑内容，不会上传至开发者服务器。

7. 数据控制

用户可以通过浏览器扩展管理页面停用或卸载扩展，并删除相关扩展数据。

8. 隐私政策更新

如果扩展的数据处理方式发生变化，我们会更新本页面内容。
