# 方案深度审查

## 核心流程

1. **逐问题追问** — 每次只问一个问题
2. **遍历决策树** — 沿每个分支深入，不浮于表面
3. **主动推荐方案** — 每个问题给出 AI 推荐的答案
4. **代码优先** — 能查代码回答的问题优先查代码

## 追问维度

| 维度       | 关注点                               |
| ---------- | ------------------------------------ |
| 边界条件   | 空状态、加载态、错误态、极端输入     |
| 数据流向   | 数据从哪来、谁负责、如何传递更新     |
| 状态管理   | 本地/持久化、冲突优先级              |
| 兼容性     | 与现有代码集成方式、是否破坏已有功能 |
| 安全与性能 | XSS/CSRF 风险、大数据性能            |
| 依赖关系   | 外部模块依赖、旧逻辑是否可复用       |
| 用户交互   | 操作路径、快捷键                     |

## 结束条件

满足任一即结束并总结：

- 所有分支决策已解决
- 用户主动表示结束
- 方案达到可执行清晰度

结束时总结：已确认决策、仍存风险、建议下一步行动。
